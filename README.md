# Credit Card Default Prediction Model

## 📌 Project Overview

This project uses Machine Learning algorithms to predict whether a credit card customer is likely to default on their payment next month. It analyzes customer demographics, credit limits, repayment history, bill amounts, and payment details.

## 🎯 Objectives

* Analyze credit card customer data.
* Perform data cleaning and preprocessing.
* Explore default payment patterns using EDA.
* Identify factors influencing credit card defaults.
* Build and compare Machine Learning models.

## 📊 Dataset

**UCI Credit Card Default Dataset**

* 30,000 records
* 25 columns
* Target Variable: `default.payment.next.month`
* `0` – No Default
* `1` – Default

## 🛠️ Technologies Used
